# Rentora

Premium Property, Tenant & Rent Management System.

## Current state
Phase 1 foundation preview: responsive homepage and placeholder admin/tenant routes. **Not production-ready.** No authentication, tenant database, payment processing, or secure document storage is implemented. Do not enter personal or financial information.

## Run locally or in GitHub Codespaces

```bash
npm install
npm run dev
```

Open port 3000 in Codespaces **Ports** panel.

## Roadmap
1. Authentication and role isolation
2. Four suites and tenant records
3. Rent invoices, partial payments and admin verification
4. Reports, messaging, documents and audit logs
5. Security testing and production deployment
